# Contributing

When contributing to this repository, please follow EUROCONTROL change control process.
Use the defined branching strategy for the project.
Update the History log in the readme file

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a
   build using Terraform CLI without a backend.
   Use Gitignore to remove all data that should not be pushed to the repository.
2. Update the README.md with details of changes to the interface, this includes new
   variables, exposed ports, useful file locations and container parameters.
3. Increase the version numbers in any examples files and the README.md to the new version that this
   Pull Request would represent. The versioning scheme we use is [SemVer](http://semver.org/).
4. You may merge the Pull Request in once you have the approvals
