This is an example for setting-up a an Azure VM Windows.
This example:

- Sets the different Azure Region representation ( location, location_short, location_cli ...) --> module "regions"
- Instanciates a map object with the common Tags ot be applied to all resources --> module "base_tagging"
- A resource-group --> module "resource_group"
- Creates Azure VM Windows with autogenerated VM name (no need to provide value of custom_name variable) --> module "vmwindows"
- Set the default diagnostics settings (All Logs and metric) whith a Log Analytics workspace as destination
- Assigns subnet to created VM
- Selects VM image from predefined images list --> windows_distribution_name
